# RAP Alignment Stage-A Loss Component Diagnostics

在本次三个 400-step FullAlign run 中，spatial raw loss 均未达到首行值的 50%，global raw loss 在 global step 80/103/107 首次达到首行值的 1%，align_share 的逐步时间均值为 0.0509%–0.0561%，且三个 1% 时点均早于实际 grl_lambda 首次达到 0.09 的 global step 119。

本报告只读取训练期产物，不读取或联系任何评测指标。A2 是 loss 数值占比的代理量，不是梯度贡献占比。

## 数据与方法

- 六个 `loss_components.jsonl` 均为 400 行，每行对应一个 optimizer step，`global_step` 为 1–400。
- A1 分位数使用线性插值；20 个等距点为 global step 1, 22, …, 400，间隔 21。
- A2 严格按给定公式逐行计算，表中换算为百分比；时间平均是 400 行的简单算术平均。
- A3 使用首次满足 `raw_loss <= 首行值 × 阈值` 的落盘行。
- A4 的 `grl_lambda` 直接读取 `loss_components.jsonl`，未按理论公式重算。
- `domain_accuracy` 位于 FullAlign 各 run 的 `csv_logs/version_0/metrics.csv`，每 epoch 一个非空 train 记录，共 20 点；原始 CSV step 为 0-based 的 19, 39, …, 399，未插值或映射。少量落盘聚合值略高于 1.0，以下原样保留并只表述为约 1.0。

输入路径、SHA256 和行数完整记录在 `outputs/alignment_stage_a/summary/loss_component_diagnostics.json`。

## 方法学限制

L1  **loss 量级不等于梯度贡献。** 一个数值很小的 loss 项仍可能产生较大梯度，取决于 ∂L/∂θ 而非 L 本身。A2 的占比是**代理指标，不是证明**。

L2  训练期**未记录 gradient norm**（Phase 4 已确认）。因此从现有产物**无法给出 alignment 梯度贡献的确定性结论**。报告必须显式写明这一点，不得把 A2 的占比表述成「梯度贡献占比」。

L3  即便发现 global alignment 贡献极小，这也只是**本次实现在 400 步、2,498 样本、且 real/raster 域极易区分条件下的观测**，不构成对 global alignment 方法本身的评价。措辞必须限定在本次 run。
